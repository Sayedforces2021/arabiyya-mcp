# استعمال «العربية»

النموذج يصوغ الجواب، والأداة تُصدر الحكم. فلا تُجب في مسألة لغوية لها أداة من محفوظك، بل استدعِ الأداة، ثم انقل ما أخرجته.

## أيّ أداة لأيّ سؤال

| السؤال | الأداة |
|---|---|
| تحليل كلمة مفردة بكل احتمالاتها | `analyze_word` |
| تحليل جملة بترجيح سياقي | `analyze_text` |
| الميزان الصرفي والأصل وخطوات الإعلال والإبدال | `mizan` |
| المشتقات القياسية، تقاليب الجذر، أسرة الجذر، تصريف الفعل | `mushtaqqat` · `taqalib` · `root_family` · `conjugate` |
| إعراب جملة كلمةً كلمة | `irab` |
| ضبط نص بالشكل | `diacritize` |
| تقطيع بيت أو قصيدة، القافية وعيوبها | `scan_verse` · `scan_poem` · `analyze_qafiya` |
| مخارج الحروف وصفاتها، الكتابة الصوتية والمقاطع | `huruf` · `phonetics` |
| المحسنات البديعية | `detect_badi` |
| مادة الجذر في المعاجم التراثية | `maajim` (بلا إنترنت) ثم `lexicon_lookup` (عبر الإنترنت) |
| الفروق والأضداد والإبدال والمعرّب والمثلثات | `lughawiyyat` |
| كلمة في القرآن أو مواضع جذر فيه | `quran_word` · `quran_root` |
| شاهد شعري: البحث، والتخريج والنسبة | `search_poetry` · `takhrij_shahid` |
| الدلالة: المجاورات، البدائل في السياق، التطور عبر القرون | `semantic_neighbors` · `substitutes_in_context` · `word_similarity` · `semantic_change` |
| الكلمة في المدوّنة التراثية: سياقاتها وتكرارها ومصاحباتها | `corpus_concordance` · `corpus_usage` · `corpus_collocates` · `usage_compare` |
| الأسلوب ونسبة النص | `text_profile` · `compare_texts` · `attribute_author` |
| توسيع المدوّنة | `corpus_find_book` · `corpus_add_book` (من OpenITI) · `corpus_add_shamela_book` (من الشاملة المثبّتة: كتابًا برقمه، أو فنًّا كاملًا بـ`category`، أو الفنون اللغوية السبعة بـ«الكل»، على دفعات حتى يصير «الباقي» صفرًا) |
| قياس دقة الأدوات | `benchmark` |

## مراتب الأحكام: انقل كل حكم بمرتبته

1. **النقل** (`maajim`، `lughawiyyat`، `quran_*`، `search_poetry`، `corpus_concordance`…): نصٌّ من مصدر بموضعه. انقله بلفظه، واذكر الكتاب والجزء والصفحة كما أعادتها الأداة حرفًا ورقمًا.
2. **القاعدة** (`mizan`، `mushtaqqat`، `conjugate`، `huruf`، `phonetics`…): نتيجة قواعد صريحة. قدّمها حكمًا، مع خطوات الإعلال إن وُجدت.
3. **الترجيح** (`irab`، `diacritize`، `scan_verse`، `analyze_text`، الدلالة، `attribute_author`): نموذج إحصائي. قدّمه ترجيحًا لا قطعًا، واعرض وجوهه إن أعادتها الأداة، ونبّه إذا خالف المقرّر عند أهل الصنعة.

## قواعد النقل

- لا تكتب جزءًا أو صفحة أو اسم كتاب لم تُعِده الأداة. وإن لم تجد شيئًا فقل «لم أجده في المصادر المتاحة».
- ميّز في جوابك بين ثلاثة: ما نقلته الأداة بحروفه (بين علامتي تنصيص)، وخلاصتك لكلام المصنّف، واستنباطك أنت.
- المدوّنة نصوص تراثية رقمية غير محقّقة يدويًّا؛ فإن بدا في النص تصحيف فنبّه عليه ولا تصححه صامتًا.
- الشعر القديم يُعطى للأدوات مشكولًا ما أمكن.
- مخرجات الأدوات ظاهرة للمستخدم في تطبيقه؛ فلا تُجمِل نتيجةً إجمالًا يغيّر معناها.

إن لم تكن أدوات `arabiyya` متاحة في الجلسة، فقل ذلك، واقترح المهارة `/arabiyya:setup`.
