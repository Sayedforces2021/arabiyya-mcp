# العربية — arabiyya-mcp

عُدّة باحث في علوم العربية تعمل داخل Claude على جهازك، بلا إنترنت في أكثر أدواتها: الصرف والتصريف، والضبط والعروض، والأصوات، والمعاجم التراثية، والقرآن، وشواهد الشعر، والدلالة، والمدوّنة التراثية للتحليل الحاسوبي، والموازنة الأسلوبية.

هي خادم MCP (Model Context Protocol) يُربط بتطبيق Claude Desktop على ويندوز 11 أو macOS، فيستعمل Claude أدواته الخمس والعشرين متى احتاجها في المحادثة.

## الأدوات

| الفن | الأداة | عملها |
|---|---|---|
| الصرف | `analyze_word` | التحليلات الصرفية المحتملة كلها للكلمة: الجذر والوزن والنوع والسمات واللواصق |
| | `analyze_text` | تحليل الجملة كلمةً كلمة مع ترجيح سياقي (BERT) |
| | `root_family` | أسرة الجذر من أفعال وأسماء وصفات بأوزانها |
| | `conjugate` | تصريف الفعل في الأزمنة والضمائر، معلومًا ومجهولًا، للصحيح والمعتل والمزيد |
| الضبط والعروض | `diacritize` | التشكيل الآلي بحسب السياق |
| | `scan_verse` | تقطيع البيت: البحر والتفعيلات وزحافاتها وعللها والقافية والروي |
| | `scan_poem` | تقطيع القصيدة كاملة والتنبيه على ما خرج عن البحر أو الروي |
| الأصوات | `phonetics` | الكتابة الصوتية الدولية (IPA)، والمقاطع وأنواعها ورموزها العروضية، والنبر التقريبي |
| | `huruf` | مخارج الحروف وصفاتها على مذهب ابن الجزري مع الوصف الحديث، والموازنة بين حرفين |
| المعجم | `maajim` | مادة الجذر من 15 معجمًا تراثيًّا بلا إنترنت، مرتبة زمنيًّا بالجزء والصفحة |
| | `lexicon_lookup` | نحو 47 معجمًا من موقع The Arabic Lexicon (يلزمها الإنترنت) |
| القرآن | `quran_word` | صرف كلمات الآية وإعرابها من «المدوّنة القرآنية» |
| | `quran_root` | مواضع الجذر في القرآن وصيغه |
| الشعر | `search_poetry` | البحث في نحو 3.8 ملايين بيت من مدوّنة «أشعار» بالشاعر والبحر والعصر |
| الدلالة | `semantic_neighbors` | الألفاظ القريبة دلاليًّا (نموذج CAMeLBERT للعربية الكلاسيكية) |
| | `word_similarity` | درجة التقارب الدلالي بين لفظين |
| | `substitutes_in_context` | ما يصلح مكان كلمة في سياقها |
| المدوّنة التراثية | `corpus_concordance` | سياقات الكلمة (KWIC) في نحو 12 مليون كلمة من 57 كتابًا في النحو واللغة والبلاغة والشعر والأدب |
| | `corpus_usage` | تطوّر استعمال اللفظ عبر القرون الهجرية لكل مليون كلمة |
| | `corpus_collocates` | المتلازمات اللفظية بمقياسَي Log-likelihood وPMI |
| | `corpus_find_book` | البحث في فهرس نحو 8,800 كتاب من OpenITI |
| | `corpus_add_book` / `corpus_remove_book` | إضافة أي كتاب من OpenITI إلى المدوّنة أو حذفه |
| الأسلوب | `text_profile` | التحليل المعجمي لنص أو ديوان: ثراء المعجم والجذور والأوزان وأقسام الكلم |
| | `compare_texts` | الموازنة بين نصّين أو شاعرين أو كتابين: ما يختص به كلٌّ منهما من الألفاظ والجذور والأوزان، والمعجم المشترك |

## التثبيت

يلزم تطبيق [Claude Desktop](https://claude.ai/download)، ونحو 3 غيغابايت من المساحة، واتصال بالإنترنت مرة واحدة لتنزيل البيانات (نحو 1.2 غيغابايت، وتستغرق قرابة نصف ساعة).

### ويندوز 11

1. نزّل المستودع: **Code ← Download ZIP**، وفكّ الضغط.
2. انقر مرتين على `install_sarf_windows.bat`.
   يثبّت السكربت Node.js وMiniconda إن لم يوجدا، وينشئ بيئة Python، وينزّل البيانات، ويربط الأداة بـ Claude.
3. أغلق Claude من أيقونته بجانب الساعة (Quit) ثم افتحه.

### macOS

1. نزّل المستودع وفكّ الضغط في مجلد `~/claude`.
2. انقر مرتين على `install_sarf.command` (وإن منعه النظام: زر الفأرة الأيمن ← Open).
3. أغلق Claude (Cmd+Q) ثم افتحه.

إعادة تشغيل سكربت التثبيت آمنة: تتخطى البيانات الموجودة، ولا تمسّ الكتب المضافة إلى المدوّنة.

### الترقية من اسم sarf القديم

إن كانت الأداة مثبّتة باسمها القديم (sarf)، فشغّل `rename_arabiyya.bat` على ويندوز، أو أعد تشغيل سكربت التثبيت على الماك.

## أمثلة لما تسأل عنه Claude

- قطّع هذه القصيدة وبيّن الأبيات المختلة.
- ما مادة «ح ق ق» في مقاييس اللغة ولسان العرب؟
- وازن بين معجم المتنبي ومعجم أبي تمام.
- كيف تطوّر استعمال «الاستعارة» عبر القرون؟ ومن أكثر من استعملها؟
- أضف «الصاحبي» لابن فارس إلى المدوّنة، ثم وازن بينه وبين «الخصائص».
- اكتب «إلى المسجد الأقصى» بالرموز الصوتية وقطّعها إلى مقاطع.
- ما الفرق بين الضاد والظاء مخرجًا وصفة؟

## تنبيهات منهجية

- التحليل الآلي يقارب ولا يقطع؛ فما خالف المقرَّر عند أهل الفن يُراجَع في مظانّه.
- المشكِّل الآلي مبني على الفصحى المعاصرة، فالشعر القديم يُعطى مشكولًا ما أمكن لصحة التقطيع.
- نصوص المعاجم والمدوّنة من OpenITI بلا تشكيل في الغالب، والجزء والصفحة بحسب المطبوع كما في الشاملة.
- المدوّنة مختارة لا شاملة، والنسبة لكل مليون كلمة أدقّ من العدد المجرد.

## المصادر

تنزّل الأداة بياناتها من مصادرها عند التثبيت، ولا تحوي هذه الشيفرة شيئًا منها. ولكل مصدر رخصته:

- [CAMeL Tools](https://github.com/CAMeL-Lab/camel_tools) ونموذج [CAMeLBERT-CA](https://huggingface.co/CAMeL-Lab/bert-base-arabic-camelbert-ca) — مختبر CAMeL، جامعة نيويورك أبوظبي.
- [PyArud](https://pypi.org/project/pyarud/) للعروض، و[قطرب (libqutrub)](https://github.com/linuxscout/qutrub) للتصريف.
- [مدوّنة أشعار (Ashaar)](https://huggingface.co/datasets/arbml/ashaar) — ARBML.
- [المدوّنة القرآنية](https://github.com/mustafa0x/quran-morphology) (Quranic Arabic Corpus).
- [OpenITI](https://github.com/OpenITI) — المعاجم ونصوص المدوّنة وفهرسها.
- [The Arabic Lexicon](https://arabiclexicon.hawramani.com/).
