# مراجعة الإعراب الآلي

ثلاثون جملة (15 سهلة و15 خلافية: آيات وشعر ومسائل خلاف مشهورة) بإعراب أداة `irab` لكل كلمة، لمراجعتها يدويًّا (صح/خطأ).

- `irab_review_sheet.pdf`: الورقة التي تُعطى للمراجع (لا تُظهر أيّها سهل وأيّها خلافي).
- `items_with_tool_output.json`: الجمل ومخرجات الأداة، وحقل `kind` (سهل/خلافي) للتحليل لاحقًا.
- `run_irab.py`: يشغّل الأداة على الجمل (يلزم بيئة العربية المثبّتة).
- `build_sheet.py`: يبني الورقة من الـJSON.

هذه المراجعة تقيس دقة الأداة، وليس عندنا إعراب مرجعي لهذه الجمل؛ حكم المراجع هو المرجع.
